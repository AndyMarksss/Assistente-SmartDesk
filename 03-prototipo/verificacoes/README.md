# Verificações do protótipo

Um relatório por versão, do `verificacao-v0.1.0.md` ao mais recente. Cada um registra como a versão foi conferida: testes automáticos, medições no navegador (tamanhos de tela, rolagem, contraste), conferência no GitHub Pages e o que ficou pendente. Os relatórios descrevem testes técnicos, não sessões com usuários.

| Arquivo | O que é |
|---|---|
| `verificacao-vX.Y.Z.md` | Relatório da versão X.Y.Z. O mais recente é o de número maior (veja [`../VERSAO.md`](../VERSAO.md)). |
| `verificacao-google-2026-10-01.md` | Primeiras tentativas de envio real para a planilha e o Drive, que levaram ao chamado #001. |
| `verificacao-acesso-v0.7.1.md` | Acesso ao painel pelo Live Server e pelo servidor local, e primeira leitura real dos chamados da planilha. |
| `contraste-v0.8.*.json`, `auditoria-v0.8.11.json` | Medições automáticas de contraste de cores e de layout. |
| `confirmacao-google-teste-001.json` | Resposta do Apps Script ao primeiro chamado de teste. |

O que mudou em cada versão está no [`CHANGELOG.md`](../CHANGELOG.md).
