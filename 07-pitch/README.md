# 07 · Vídeo pitch

Vídeo de até **4 minutos**, como se eu apresentasse aos fundadores da startup os resultados de uma rodada de validação. Ainda não foi gravado. A ordem é: parte prática pronta (sessões, síntese e decisão) → roteiro, guardado em `roteiro/` → gravação → link no README de entrega → PDF da entrega, que leva o link.

## O que o vídeo precisa mostrar (enunciado)

1. Problema e hipótese inicial.
2. Solução proposta.
3. Experimento realizado.
4. Evidências obtidas com os usuários.
5. O que os dados confirmaram ou contrariaram.
6. Decisão tomada (perseverar, ajustar, pivotar ou abandonar) e próximo passo recomendado.

## Materiais

- Roteiro e slides: serão guardados aqui (`roteiro/` e `slides/`).
- Imagens prontas para usar: [Lean Canvas](../06-documentacao/canvas/lean-canvas.png) e prints em [`05-evidencias`](../05-evidencias/README.md).
- Publicação: YouTube (não listado) ou Google Drive, conferindo se o link abre numa janela anônima antes de enviar.
